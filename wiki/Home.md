# Bem-vindo(a) à Wiki do Bárbara Reis Nail Designer 💅

Este repositório contém o sistema completo de gerenciamento para o estúdio **Bárbara Reis Nail Designer**. Ele foi construído pensando na agilidade do dia a dia, garantindo o controle total de clientes, agenda e fluxo financeiro.

## 🎯 Objetivo do Sistema

Centralizar toda a gestão do estúdio de forma profissional e automatizada, abandonando o papel e planilhas confusas. Com este sistema, é possível ter uma visão unificada e em tempo real sobre a saúde do negócio.

## 💻 Stack Tecnológico (O que usamos?)

A aplicação foi desenvolvida seguindo uma arquitetura moderna dividida entre Frontend (Interface) e Backend (API/Servidor), além de um banco de dados hospedado na nuvem.

### Frontend

- **React.js + Vite**: Para uma interface de usuário extremamente rápida (SPA).
- **Tailwind CSS**: Estilização rica, responsiva e com suporte a *Glassmorphism* (efeitos de vidro translúcido).
- **Lucide React**: Ícones leves e consistentes.
- **React Router**: Navegação suave sem recarregar a página.

### Backend

- **Node.js + Express**: Servidor robusto e assíncrono para consumir a API.
- **Prisma ORM**: Comunicação limpa, tipada e segura com o banco de dados.
- **JWT + bcrypt**: Criptografia de senhas e proteção de rotas com tokens e cookies *HTTP-Only*.

### Infraestrutura e Banco de Dados

- **PostgreSQL**: Banco de dados relacional sólido hospedado no **Supabase**.
- **Render**: Plataforma de nuvem responsável por manter o Frontend (Static Site) e o Backend (Web Service) sempre online.
